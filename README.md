# 3D 萌寵成長日記 🐾 (3D Pet Growth Diary)

全 3D 網頁萌寵養成與互動遊戲，支援 24 種高精細 3D 萌寵：大熊貓、耳廓狐、長頸鹿、北極熊、海獺、無尾熊、垂耳兔、獅子、水豚、小熊貓、雪豹、帝企鵝、安地斯神鷲等！

## 🌟 遊戲特色
- **完全純前端 3D 渲染**：基於 Three.js 打造，無需安裝任何外掛或 App。
- **24 種獨特 3D 寵物**：每種寵物均有專屬外觀建模、特徵、幼崽/成年雙形態切換。
- **完整互動系統**：餵食、梳毛、洗澡、訓練、接飛盤、小遊戲賺金幣與多種裝扮道具。
- **真實 Web Audio 音效**：內建音頻合成器，還原各類動物專屬叫聲。
- **本地進度自動存檔**：支援 LocalStorage 自動存檔與存檔管理。
